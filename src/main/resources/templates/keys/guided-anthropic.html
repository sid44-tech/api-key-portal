Add an Anthropic API key

Anthropic API keys can only be created by hand in the Anthropic console - there is no API for it. This walk-through covers the manual steps; afterwards the portal verifies the pasted key live against the Anthropic API (a free call, no tokens billed) and stores it encrypted.

Create a key in the Anthropic console

  1. Open the API keys page with the button below and sign in.
  2. Press Create key.
  3. Give it a descriptive name and, if you use workspaces, pick the right one - keys are scoped to a workspace and its spend limits.
  4. Press Create.
