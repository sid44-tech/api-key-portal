The portal will register a new client in tenant tenant, generate a client secret for it, and store the secret here encrypted. You never have to touch the Azure portal or copy anything.

The portal will create a new service account in project project, generate a JSON key for it, and store the key here encrypted. You never have to touch the Google Cloud console or copy anything.

The portal will create a project access token in project (scope api, role Maintainer) and store it here encrypted. You never have to touch GitLab or copy anything.

The portal will create an API token copying the permissions of your template token, and store it here encrypted. You never have to touch the Cloudflare dashboard or copy anything.

The portal will create a new IAM user in account account, generate an access key pair for it, and store the pair here encrypted. You never have to touch the AWS console or copy anything.
