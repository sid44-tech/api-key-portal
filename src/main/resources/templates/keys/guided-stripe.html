Add a Stripe API key

Stripe API keys can only be created by hand in the Stripe dashboard - there is no API for it. This walk-through covers the manual steps; afterwards the portal verifies the pasted key live against the Stripe API and stores it encrypted.

Create a restricted key in the Stripe dashboard

  1. Open the API keys page with the button below and sign in.
  2. Press Create restricted key. Prefer this over the account's standard secret key, which can do everything.
  3. Name it after what will use it, then grant only the resources that consumer needs - Read where Write isn't required.
  4. Press Create key.
Open "API keys" in the Stripe dashboard

Mind the test/live toggle at the top of the dashboard. A live key (sk_live_ / rk_live_) moves real money; the portal records which mode the key is in on the key's notes.

2

Copy the key and paste it here

Stripe reveals a restricted key (it starts with rk_) once, right after creating it. Copy it and paste it below.

Stored encrypted (AES-256-GCM). The portal verifies it against the Stripe API before saving, so typos surface right here.
