Add an Atlassian API token

Atlassian API tokens can only be created by hand in your Atlassian account settings - there is no API for it. This walk-through covers the manual steps; afterwards the portal verifies the token live against Atlassian and stores it encrypted. One token works across the suite: Jira, Confluence, Bitbucket's Jira-backed APIs and the rest.

Create a token in your Atlassian account

  1. Open the API tokens page with the button below and sign in.
  2. Press Create API token.
  3. Give it a descriptive label — it is how you'll recognise it later in the list, and the only thing shown there once it's created.
  4. Pick an expiry. Atlassian allows up to a year; shorter is better practice, and the portal will remind you before it runs out.
  5. Press Create.
Open "API tokens" in your Atlassian account

A token carries your own permissions in every Atlassian site you can reach — there is no way to scope one down. Prefer a dedicated service account over a person's login for anything shared.

2

Copy the token, and the email it belongs to

Atlassian shows the token exactly once, right after creating it. An Atlassian token is only half of the credential: calls authenticate as email plus token, so the portal needs both — and checks them together.

The address you signed in with above.

The token is stored encrypted (AES-256-GCM); the email goes in the notes, since it is not a secret and whoever uses the token will need it.
