Add a GitHub personal access token

GitHub tokens can only be created by hand in GitHub's settings - there is no API for it. This walk-through covers the manual steps; afterwards the portal verifies the pasted token live against GitHub, picks up its expiry date automatically, and stores it encrypted.

Create a fine-grained personal access token

Fine-grained tokens are the recommended kind: they're scoped to chosen repositories and permissions, and always have an expiry.

  1. Open the token form with the button below (you may need to confirm your password).
  2. Give it a descriptive name and pick an expiration.
  3. Under Repository access, select only the repositories it needs.
  4. Under Permissions, grant the minimum it needs (e.g. Contents: Read-only for a CI checkout token).
  5. Press Generate token.
Open "New fine-grained token" on GitHub

Need a classic token instead (some tools still require one)? Create it under Tokens (classic) - the rest of this page works the same, and the portal records its scopes for you.

Copy the token and paste it here

GitHub shows the token (it starts with github_pat_ or ghp_) exactly once, right after generating it. Copy it and paste it below.

Stored encrypted (AES-256-GCM). The portal verifies it against GitHub before saving and reads the expiry date from GitHub's response, so you don't have to enter it.
