Add an OpenAI API key

OpenAI API keys can only be created by hand in the OpenAI platform - there is no API for it. This walk-through covers the manual steps; afterwards the portal verifies the pasted key live against the OpenAI API (a free call, no tokens billed) and stores it encrypted.

Create a key in the OpenAI platform

  1. Open the API keys page with the button below and sign in.
  2. Press Create new secret key.
  3. Give it a descriptive name, pick the right project - keys are scoped to a project and its spend limits - and prefer Restricted permissions where the consumer allows it.
  4. Press Create secret key.
