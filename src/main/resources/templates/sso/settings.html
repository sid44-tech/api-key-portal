Single sign-on

Let people sign in with your organisation's identity provider. Access is granted by putting someone in a directory group — nobody gets in without it.

Error
Before you start

Register this portal as an application in your identity provider (an app registration in Microsoft Entra ID, an OIDC web app in Okta or Google Workspace), then paste its details below. The portal reads everything else from the provider's OpenID configuration.

Give the provider exactly this. It must be reachable by the person signing in, so set PORTAL_BASE_URL if the portal sits behind a proxy.

Then make the provider send group membership: in Entra ID that is Token configuration → Add groups claim, choosing Groups assigned to the application so the claim stays small.
