Connect Twilio

A one-time setup, done in about three minutes. You'll create one API key for this portal to manage keys with. Afterwards, the portal can create Twilio API keys in your account with a single click.

Create a Main API key for the portal

  1. Sign in to the Twilio Console and open Account → API keys & tokens → Create API key.
  2. Name it Key Management Portal (any name works) and leave the region on United States (US1).
  3. Set the key type to Main and create it.

Twilio only lets a Main key create and delete other keys, and a Main key has the same reach as your Auth Token. That is why it is stored encrypted and never shown again. Every key the portal creates is a Standard key, which can use Twilio's APIs but cannot manage keys or the account.
