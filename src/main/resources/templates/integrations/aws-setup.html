Connect Amazon Web Services

A one-time setup, done in about five minutes. You'll create one IAM user for this portal, allowed to do exactly one thing: manage IAM users under the /keyportal/ path. Afterwards, the portal can create IAM users and access keys in your account with a single click.

1

Create a policy that scopes the portal down

Sign in to the AWS console as an administrator, open IAM → Policies → Create policy, switch to the JSON tab and paste:

{
  "Version": "2012-10-17",
  "Statement": [{
    "Effect": "Allow",
    "Action": [
      "iam:CreateUser",
      "iam:CreateAccessKey",
      "iam:DeleteAccessKey",
      "iam:DeleteUser"
    ],
    "Resource": "arn:aws:iam::*:user/keyportal/*"
  }]
}

Name it APIKeyPortalProvisioning (any name works) and create it.

This is the least-privileged option: every user this portal creates lives under the /keyportal/ path, and the policy reaches that path and nothing else. The portal cannot touch any other user, role or resource in your account. iam:DeleteAccessKey is what lets automatic replacement finish the job: once a key has expired and its successor exists, the old pair is deleted.

Open "Create policy" in the AWS console
2

Create an IAM user for the portal

  1. Open IAM → Users → Create user.
  2. Name it api-key-portal (any name works).
  3. Leave Provide user access to the AWS Management Console unticked — this user is for API calls only.
  4. On the permissions step choose Attach policies directly and tick the policy from step 1, then create the user.
Open "Create user" in the AWS console
3

Create that user's access key

  1. Open the new user, choose Security credentials → Create access key.
  2. Pick Third-party service as the use case and confirm.
  3. Copy both values below — AWS shows the secret only once.

Stored encrypted (AES-256-GCM) and never shown again in this portal either.

4

Copy your account ID

Open the account menu (top right of the console); the twelve-digit Account ID is at the top of it. The portal checks the key you pasted really belongs to this account before saving anything.

5

Name it and connect

This name shows up in the provider dropdown on the Add key screen, and as the service name on keys created through it.

The portal verifies the connection against AWS before anything is saved, so typos surface right here.
