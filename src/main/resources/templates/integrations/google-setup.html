Connect Google Cloud

A one-time setup, done in about five minutes. You'll create a service account for this portal in your Google Cloud project and paste its JSON key back here. Afterwards, the portal can create service accounts and keys in that project for you with a single click.

1

Enable the IAM API in your project

The portal talks to the Identity and Access Management (IAM) API to create service accounts and keys. Sign in to the Google Cloud console, pick the project you want keys created in, then enable the API:

Open the IAM API page and press "Enable"
2

Create a service account for this portal

This is the identity the portal acts as in your project:

  1. Open the creation form with the button below (check the right project is selected in the top bar).
  2. Name it api-key-portal (any name works) and press Create and continue.
  3. Under Grant this service account access to project, add the roles Service Account Admin and Service Account Key Admin, then press Done.
Open "Create service account" in the Google Cloud console

These roles only allow managing service accounts and their keys in this one project - nothing else in your Google Cloud account.

3

Download a JSON key and paste it here

  1. Open your new service account from the list and switch to the Keys tab.
  2. Press Add key → Create new key, keep JSON selected and press Create. The key file downloads automatically.
  3. Open the downloaded file in a text editor and paste its entire contents below, then delete the file.

The project ID and service account email are read from the pasted key; the private key is stored encrypted (AES-256-GCM) and never shown again in this portal either.

4

Name it and connect

This name shows up in the provider dropdown on the Add key screen, and as the service name on keys created through it.

The portal verifies the connection against Google Cloud before anything is saved, so typos surface right here.
