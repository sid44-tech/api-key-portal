Create an API key for the portal

  1. In SendGrid, open Settings → API Keys → Create API Key.
  2. Name it Key Management Portal (any name works).
  3. Choose Restricted Access, set API Keys to Full Access, and give it every other permission you want the portal's keys to be able to have - at least Mail Send.
  4. Create it and copy the key - SendGrid shows it only once.

SendGrid only lets a key hand out permissions it has itself, so this key's permissions are the ceiling for every key the portal creates. Keys the portal creates never get key management themselves.
