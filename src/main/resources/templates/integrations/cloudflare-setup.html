Connect Cloudflare

A one-time setup, done in about five minutes. Cloudflare token permissions are too rich to rebuild as a form here, so the portal doesn't try: you craft one template token in Cloudflare's own editor, and every token the portal mints is a copy of that template's permissions with its own name and expiry.

Create the portal's own API token

This is the token the portal acts with. It can mint and read tokens, and do nothing else — not touch zones, DNS or anything behind them.

  1. Open My Profile → API Tokens → Create Token.
  2. Scroll to Create Custom Token, name it api-key-portal.
  3. Give it exactly one permission: User → API Tokens → Edit.
  4. Create it, copy the value — Cloudflare shows it only once — and paste it below.
Open "API Tokens" in the Cloudflare dashboard
2

Create the template token

Still under API Tokens → Create Token, create a second token carrying exactly the permissions you want every portal-minted token to have — say, Zone → DNS → Edit on one zone. Name it something recognisable like portal-template.

Back on the API Tokens list, use the token's ⋯ menu → Copy ID (or open it) and paste the ID below.

The template's value is never entered here and the token itself is never used — only its permission list is copied, read fresh each time. Edit the template in Cloudflare and every key minted afterwards picks up the change.

3

Name it and connect

This name shows up in the provider dropdown on the Add key screen, and as the service name on keys created through it.

The portal verifies the token and reads the template against Cloudflare before anything is saved, so typos surface right here.
